# Support / Suporte

## Before reporting a problem

1. Use Minecraft Java `1.21.1`, Java 21 and a supported NeoForge `21.1.x` build.
2. Confirm only one TikTok Chaos JAR is present in `mods`.
3. Test the same rule in the in-game **Simulator**.
4. Check whether the LIVE is public and currently active.
5. Search existing GitHub issues.

## What to attach

- TikTok Chaos, NeoForge and modpack versions.
- Exact steps that reproduce the problem.
- `logs/latest.log` for normal errors.
- The matching file from `crash-reports/` for a crash.
- A mod list when compatibility is involved.
- Screenshots for visual/layout problems.

Do not publish passwords, login cookies, CurseForge tokens, GitHub tokens or other credentials.

---

## Antes de pedir ajuda

1. Use Minecraft Java `1.21.1`, Java 21 e NeoForge `21.1.x` compatível.
2. Confirme que existe apenas um JAR do TikTok Chaos na pasta `mods`.
3. Teste a mesma regra no **Simulador** do mod.
4. Confira se a LIVE está pública e acontecendo naquele momento.
5. Pesquise os issues já existentes no GitHub.

Ao relatar, informe versões, passos exatos e anexe `logs/latest.log` ou o crash report correspondente. Capturas de tela são úteis para problemas visuais, mas uma captura da janela de crash não substitui os logs.
